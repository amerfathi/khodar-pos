# BRAKA 2.6.11 — 2026-10-01

## Changes

- Preserve unsaved settings form edits when the application store refreshes during sync or another state update. Untouched fields continue to accept current settings.
- Recover an invalid or missing local branch selection from the authenticated server branch manifest only when saved records can be safely matched. Local financial rows and pending mutations remain intact; ambiguous or unrecognized branch data still blocks financial access.

## Verification and limitations

- A focused UI regression reproduced settings text reverting before Save, then passed after the form was changed to preserve dirty fields during unrelated store refreshes.
- Security, integration, and accounting test suites, lint, core typecheck, and production build passed.
- Windows installer and Android debug APK were built locally. Android signing/release packaging and installation upgrade were not tested.
- Production Web deployment contains both fixes. Existing desktop and Android installations need the 2.6.11 release to receive them.
